# 📚 문법영상 학습 사이트

학원 문법 영상(네이버 마이박스에 올려둔 강의)을 학생별 진도에 맞춰 자동으로 이어서
보여주는 사이트입니다. 학생은 이름을 선택해 입장하고, 교재를 선택하면 그 안의 영상이
순서대로 연결되어 "오늘의 학습"으로 자동 추천됩니다. 이미 본 영상은 완료 표시가 되고,
복습 버튼으로 다시 볼 수도 있습니다.

## 주요 기능

- **간편 로그인**: 학생이 이름 버튼을 눌러 입장 (선택적으로 4자리 PIN 보호 가능)
- **교재 선택**: 교재를 고르면 그 안의 영상들이 순서대로 연결됨
- **자동 진도 추천**: 선택한 교재에서 아직 안 본 영상 중 가장 앞선 영상을 "오늘의 학습"으로 자동 추천
- **시청 완료 표시**: 시청 완료 버튼을 누르면 해당 영상이 완료 처리되고, 다음 방문 때 다음 영상이 추천됨
- **복습**: 이미 본 영상도 언제든 다시 열어 "복습했어요" 버튼으로 복습 기록을 남길 수 있음
- **관리자 페이지** (`/admin`, 비밀번호 보호): 교재/영상/학생 추가·수정·삭제, 마이박스 링크 등록

## 영상 연동 방식 (중요)

이 사이트는 영상 파일을 직접 저장하지 않고, **네이버 마이박스 공유 링크**를 각 영상에
연결해 iframe으로 재생을 시도합니다.

1. 네이버 마이박스에서 영상 파일 우클릭 → **공유** → **링크 만들기**
2. 만들어진 공유 링크를 복사해 관리자 페이지(`/admin` → 교재 → 영상 관리)의
   "네이버 마이박스 공유 링크" 칸에 붙여넣기

> ⚠️ 마이박스 공유 페이지가 다른 사이트에서의 iframe 삽입(임베드)을 막아둔 경우,
> 영상이 화면에 바로 재생되지 않을 수 있습니다. 이런 경우를 대비해 영상 페이지에는
> 항상 **"새 탭에서 영상 보기"** 링크가 함께 표시됩니다. 만약 iframe 재생이 계속 안 된다면
> 마이박스 링크를 유튜브(일부공개)나 다른 임베드 가능한 저장소로 옮기는 것도 고려해보세요.

## 시작하기

```bash
npm install
cp .env.example .env      # ADMIN_PASSWORD를 원하는 비밀번호로 변경하세요
npx prisma migrate dev    # DB 생성
npm run db:seed           # 예시 교재 2개 + 학생 4명 생성 (실제 데이터는 /admin에서 입력)
npm run dev
```

브라우저에서 http://localhost:3000 접속 → 학생 로그인 화면
관리자 페이지는 http://localhost:3000/admin (`.env`의 `ADMIN_PASSWORD`로 로그인)

### 데이터 초기화

시드 데이터를 지우고 다시 생성하려면:

```bash
npm run db:reset
```

## 기술 스택

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite (파일 기반 DB, `prisma/dev.db`)
- 인증: 별도 회원가입 없이 쿠키 기반 세션 (학생: 이름 선택 + 선택적 PIN, 관리자: 비밀번호)

## 배포 시 참고사항

- 기본값은 SQLite 파일(`prisma/dev.db`)을 사용합니다. **로컬 PC나 학원 내부 서버에서
  계속 실행하는 방식**이라면 이대로 사용해도 됩니다.
- Vercel 같은 서버리스 환경에 배포하면 파일 시스템이 요청마다 초기화되어 SQLite 데이터가
  유지되지 않습니다. 인터넷 어디서나 접속 가능한 형태로 배포하려면 `DATABASE_URL`을
  Postgres, Turso(LibSQL) 등 호스팅 DB로 교체해야 합니다. (스키마는 `prisma/schema.prisma`
  하나만 있어서 `datasource` 설정만 바꾸면 됩니다.)
- `ADMIN_PASSWORD`는 반드시 기본값에서 변경해서 사용하세요.

